Enums

Every enum in the framework — the generated Access, the settings VariableType, result types and dozens more — shares one interface and a trait of helpers, so they all behave the same.

The enum pattern

A framework enum implements Enum and JsonSerializable, uses the IsEnum trait, and opens with a None case (a PHPStan rule enforces both):

use Framework\Enum\Enum;
use Framework\Enum\IsEnum;
use JsonSerializable;

enum Status implements Enum, JsonSerializable {
    use IsEnum;

    case None;
    case Active;
    case Blocked;
}

Shared helpers

The IsEnum trait gives every enum the same typed API — use these rather than the native cases() / from(), which a rule disallows:

MethodDoes
fromValue(string)The case for a backing string (or None).
getAll()Every case as a list.
getNames()The case names.
isValid(value)Whether a value maps to a case.
contains(values, case)Whether a case is in a given set.
toString()The case as its string name.
jsonSerialize()Serializes to that string, so enums encode cleanly in a Response.
 
use Framework\Utils\Color;

Color::fromValue("Blue");   // Color::Blue
Color::getAll();            // [Color::None, Color::Red, …]
Color::isValid("Blue");     // true
Color::Blue->toString();    // "Blue"

Enum-keyed maps

A plain PHP array only allows int or string keys, so you can't key one by an enum case. The Map class fills that gap — a typed container whose keys are enum cases — with set, get / getInt / getString, has, count and iteration:

use Framework\Enum\Map;

$labels = new Map();
$labels->set(Status::Active,  "Active");
$labels->set(Status::Blocked, "Blocked");

$labels->get(Status::Active);   // "Active"
$labels->has(Status::None);     // false
